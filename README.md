# User Wallet

Node.js + Express + SQLite user/admin portal.

Features: user login, admin login, unlimited users, per-user balance, account number, dashboard password, direct image grid, user enable/disable, edit/delete, image upload/delete, responsive UI, local withdrawal confirmation (no real-money transfer).

## Run
1. Install Node.js 20+.
2. `npm install`
3. `npm start`
4. Open `http://localhost:3000`

Demo admin: `admin` / `Admin@12345` (change before real use).
